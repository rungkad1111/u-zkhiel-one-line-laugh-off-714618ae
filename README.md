## The line

> I asked my smart fridge for a snack, and it reported me to my doctor, my gym, and — worst of all — my mother.

## How it works

`main.ts` (Node 22, standard library only) writes exactly one funny line to `/output/entry.txt`.
It validates the gate itself before writing: the line must be a single non-blank line of 1–200
characters. Run it with:

```sh
node main.ts
```
